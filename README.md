📧 Email Sender – Spring Boot
A simple **Email Sender application** built with **Spring Boot** that allows users to send emails by providing a recipient email address, subject, and message body.
The project demonstrates how a frontend can communicate with a Spring Boot REST API, and how the backend can send emails using **Gmail SMTP**.

Features:
* Send emails using Gmail SMTP
* REST API for sending emails
* Recipient email input
* Subject input
* Email body/message input
* Frontend-to-backend API communication
* CORS configuration
* SMTP authentication
* Environment variable support for email credentials

Technologies Used:
* Java
* Spring Boot
* Spring Web
* Spring Mail
* JavaMailSender
* Gmail SMTP
* Maven
* HTML / CSS / JavaScript(if using a frontend)
